# Carry-over: open follow-ups from closed or parked work

One short list of what is still owed after a ticket closed (or stalled), so nobody has to search every plan
file to find it.

**Rules**
- One line per item: `- [ ] <what is owed> — from <TICKET / plan file>, owner <who>, added <date>`.
- Add a line when a plan moves to `done/` with something left over, or when a review leaves a finding for later.
  Delete the line (do not tick it) when the work lands, and name the PR in the change log.
- Facts only: no secrets, no personal data.
