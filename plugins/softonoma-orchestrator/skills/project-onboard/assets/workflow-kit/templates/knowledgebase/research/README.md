# Research dossiers

One folder per module or question: `research/<module>/research.md`, written by the `deep-research` skill
BEFORE any code for a new module or an unclear feature. A dossier covers the source requirement, how the
codebase already does similar things, domain or regulatory norms, the data model, edge cases, and open
questions (each answered with the assumption made, or marked as awaiting the owner).

The durable "how it works now" moves into `../modules/` once built; the dossier stays as the record of why.
